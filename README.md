# 아이콘 원정대

실행 중인 프로그램과 바탕화면 아이콘이 캐릭터가 되어 던전 탐험, 점프, 개인전 배틀, 볼링, 탑 쌓기, 낚시, 농장을 즐기는 Windows 데스크톱 앱입니다.

## 바로 체험하기

Windows에서 처음 받은 경우 Node.js를 설치하고 아래 명령으로 시작합니다.

```powershell
git clone https://github.com/kikyo424/icon-expedition.git
cd icon-expedition
npm install
npm start
```

의존성 설치 후에는 `실행.cmd`를 더블클릭해도 데스크톱 앱이 열립니다.

첫 실행에서는 현재 창이 있는 프로그램을 읽고 투명 위젯에서 자동 던전 탐험을 시작합니다. 이후에는 마지막으로 선택한 캐릭터 소스를 기억합니다. 위젯 상단 바를 끌어 이동하고, `Ⅱ`로 일시정지하거나 `↗`로 전체 설정 화면을 펼칠 수 있습니다. `×`는 앱 종료입니다. 작은 위젯 상단의 던전·점프·배틀 버튼으로 바로 게임을 바꿀 수 있습니다. 선택한 게임은 새 판으로 시작하며, 점프 최고 기록은 유지됩니다. 전체 화면에서 게임을 고른 뒤 ‘투명 위젯’을 누르면 진행 중인 게임을 위젯에서 계속합니다. 위젯 모드는 배경과 창 테두리가 투명하고 항상 위에 표시됩니다. 아이콘과 조작 바가 있는 영역은 마우스 입력을 받습니다.

`index.html`을 브라우저로 열면 설치 없이 기본 캐릭터로 세 게임을 플레이할 수 있습니다. 이미지 추가도 지원합니다.

## 데스크톱 앱 실행

Node.js와 npm이 있는 환경에서:

```powershell
npm install
npm start
```

`↗`로 전체 화면을 열어 **실행 중인 앱 / 바탕화면 파일**을 선택할 수 있습니다.

실행 중인 앱 모드는 일반 창이 있는 프로그램의 실제 아이콘과 제품 이름을 읽습니다. 같은 실행 파일의 여러 창은 캐릭터 하나로 합칩니다. 새 앱을 열면 빈 자리에 합류하고, 마지막 창을 닫으면 귀환합니다. 던전·배틀은 최대 6명, 점프는 1명이며 나머지는 대기합니다. 참가자를 클릭해 제외할 수 있고 제외 목록과 파티 우선 선택은 저장됩니다. 활성 앱은 발밑 테두리로 표시합니다. 기존 파티원의 체력과 위치는 갱신해도 유지합니다. 앱 감지기는 약 3초마다 확인하고 화면은 약 5초마다 반영하므로 변경 반영까지 몇 초가 걸릴 수 있습니다. GPT·Codex도 참가할 수 있습니다. 시스템·도구 창과 아이콘 원정대 자체만 제외하며 일부 보호된 프로그램 및 구형 UWP 호스트 창은 수집하지 못할 수 있습니다. 문서 내용이나 창 제목은 읽지 않습니다.

바탕화면 파일 모드에서는 사용자 바탕화면과 공용 바탕화면의 실제 항목 최대 60개를 캐릭터로 가져옵니다. 파일의 이름과 아이콘을 그대로 사용하며, 폴더·앱/바로가기·이미지·미디어·압축 파일·일반 문서에 따라 역할, 체력, 공격력이 달라집니다. ‘바탕화면 새로고침’으로 변경된 목록을 다시 읽을 수 있습니다. Windows Shell에서 바탕화면 항목의 표시 이름, 캐시된 미리보기와 개별 아이콘을 가져옵니다. 휴지통 등 표시 설정이 켜진 시스템 아이콘도 포함합니다. Shell 이미지를 가져오지 못하면 일반 파일 이미지가 사용될 수 있습니다. 실제 파일은 이동하거나 실행하지 않습니다. 항상 위에 표시, 작은 창 모드를 사용할 수 있습니다.

## 플레이

- 던전: 실행 앱은 최대 6인, 바탕화면 파일은 최대 3인 파티가 자동 전투합니다. 방을 클리어하면 다음 층으로 이동하며 체력을 일부 회복합니다. 5층마다 보스가 등장합니다. 진형을 유지하며 차례대로 행동하는 턴제 전투입니다. 직접 조작에서는 파티원의 차례마다 공격·스킬·방어를 선택합니다.
- 점프: 1인으로 장애물을 넘습니다. Space / 위 방향키 / 화면 터치로 점프합니다. 자동 모드도 선택할 수 있습니다.
- 배틀: 아이콘들이 중앙으로 몰려들어 동시에 공격하는 실시간 개인전입니다. 몸끼리 부딪치고 공격에 튕겨 나가며, 마지막 생존자 한 명이 우승합니다. 실행 중인 앱은 2~6명, 바탕화면 파일은 2~4명이 참가합니다. 자동 관전 또는 첫 참가자 직접 조작을 지원하며, 수동 모드에서는 방향키·WASD로 이동합니다.
- 볼링: 앱 아이콘을 공으로 사용합니다. 좌우 방향키로 조준, 위아래로 힘 조절, Space로 투구하거나 레인을 클릭합니다. 핀과 핀의 연쇄 충돌을 계산하고, 10번의 투구에서 쓰러뜨린 핀 수를 합산합니다(최대 100점, 일반 볼링의 스페어·스트라이크 보너스 규칙은 사용하지 않습니다).
- 아이콘 타워: 크기가 다른 블록을 좌우로 옮기고 Q로 회전, Space나 클릭으로 떨어뜨립니다. 무게중심이 받침 밖이면 기울고 떨어지는 간단한 물리 균형 게임입니다. 높이에 따라 카메라가 올라가며, 블록을 3개 놓치면 종료합니다.
- 낚시: Space나 클릭으로 던지고, 입질 때 다시 눌러 낚기를 시작합니다. Space 또는 마우스를 누르면 장력이 오르고 놓으면 내려갑니다. 장력을 초록 구간에 유지하면 물고기나 보물을 얻습니다. 수집 수와 코인은 저장됩니다.
- 작은 농장: 밭을 클릭하거나 좌우 방향키로 고른 뒤 Space로 심기·물주기·수확합니다. 1·2·3이나 상단 작물 버튼으로 당근·토마토·호박을 선택하고, Q로 순환합니다. 물을 주면 총 성장 시간이 35% 짧아집니다. 작물은 농장 화면에서 게임을 진행하는 동안에만 자랍니다. 다른 게임으로 전환하거나 일시정지·최소화·앱 종료 시 성장이 멈춥니다.
- 새 게임 4종 모두 자동·수동 전환과 작은 창의 게임 선택을 지원합니다. 자동 농장은 현재 고른 작물로 파종·물주기·수확을 반복하며, 낚시와 농장은 코인을 공유합니다. 선택한 게임 화면 하나만 진행하며, 다른 게임으로 전환하거나 창을 최소화한 동안에는 자동 진행이나 보상이 발생하지 않습니다. 저장은 이 기기의 앱 프로필에 보관됩니다.
- 던전·배틀: Space 기본 공격, Q 스킬, E 방어. 기본 공격·방어는 기력 +1, 스킬은 기력 2를 사용합니다. 자동 모드에서는 기력이 차면 스킬도 자동으로 사용합니다. Esc 일시정지. 작은 창에서는 Esc로 일반 화면에 돌아옵니다.
- 실행 앱은 전투 중에도 참가·제외할 수 있습니다. 바탕화면 파일 참가자 변경은 ‘다시 시작’을 눌러 준비 화면으로 돌아온 후 가능합니다.
- 전체 화면의 ‘던전 악당 이미지’에서 슬라임, 밀린 보고서, 마감 캘린더, 끝없는 업무, 고장난 프린터, 야근 시계를 여러 개 선택할 수 있습니다. 진행 중 변경하면 다음 층부터 적용됩니다. 직접 악당 이미지 추가도 지원합니다(파일당 3MB 이하). 기본 악당 선택은 저장되며, 직접 추가한 악당 이미지는 앱 종료 시 초기화됩니다.
- 작은 위젯은 560×355 고정 크기이며 크기 조절·최대화를 잠급니다. 위치 이동은 가능하며 다음 실행에도 위젯 위치를 기억합니다. 전체 설정 창에서는 크기를 조절할 수 있습니다. 캐릭터는 실행 중인 Windows 바탕화면의 아이콘 크기를 읽고 화면 배율을 반영해 같은 표시 크기로 그립니다. 실시간 조회가 불가능한 환경에서는 저장된 바탕화면 크기 설정 또는 기본 48픽셀을 사용합니다. ‘바탕화면 새로고침’ 시 크기도 다시 읽습니다.

최고 기록, 캐릭터 소스, 앱 제외 목록, 파티 우선 선택, 기본 악당 선택과 위젯 위치는 로컬에 저장됩니다. 직접 추가한 이미지와 진행 중인 전투는 재실행 시 초기화됩니다. 앱이 종료된 동안의 탐험, 장비·재화 성장, 설치 파일 패키징은 아직 제공하지 않습니다. 자동 탐험은 실행 중인 앱에서 진행하며 절전 중에는 진행되지 않습니다.

## 검증

```powershell
npm run check
npm test
```

의존성 없이도 `node --test tests/engine.test.cjs`로 전투 대상 선택, 이동, 충돌, 점프 물리를 검증할 수 있습니다.

Windows 아이콘 변환의 상하 방향 및 알파 채널 회귀 검증:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests/icon-orientation.ps1
```

브라우저 시나리오 검증은 Playwright가 있는 환경에서 `node tests/smoke.cjs`, `node tests/live-apps-smoke.cjs`로 실행합니다. Windows 데스크톱 검증은 `node tests/desktop-smoke.cjs`를 사용하며 별도의 테스트 프로필에 설정을 저장합니다.

## 턴제 스킬과 모션

작은 창에서는 상단 ☰ 메뉴로 7개 게임을 선택합니다. 자동·수동은 옆의 스위치로 바꿉니다. 게임 선택 후 메뉴가 닫히며, 바깥 클릭이나 Esc로도 닫을 수 있습니다. 메뉴에서 위아래 방향키로 이동하고 Enter로 선택합니다.

브라우저는 탭 다중 공격, 문서는 방벽, 메신저는 회복, 코드 편집기는 연쇄 공격, 미디어 앱은 음파 공격을 사용합니다. Chrome·Edge·Firefox, Excel·Word·PowerPoint, Discord·KakaoTalk의 공격 표현도 구분합니다. 폴더는 파티 방벽, 휴지통은 흡수 회복, 사진은 약화 스킬을 가집니다. 슬라임은 독, 보고서는 방벽 해제, 캘린더는 공격 감소, 프린터는 연속 출력, 야근 시계는 자기 회복을 사용합니다. 새 앱은 다음 라운드부터 행동하며, 닫힌 앱은 대기열에서도 빠집니다. 위젯에서 직접 조작할 때는 작은 공격·스킬·방어 버튼을 사용할 수 있습니다. `node tests/turn-ui-smoke.cjs`로 수동 스킬과 20개 효과 스타일을 검증합니다.

## 던전 직업과 증강

탐험을 시작하면 각 동료에게 무작위 직업 증강 3개가 제시됩니다. 수동 모드는 그중 하나를 선택하고 자동 모드는 무작위로 배정합니다. 아이콘 옆에는 직업에 맞는 무기를 표시하며 직업 이름 배지는 표시하지 않습니다. 직업이 있는 던전 동료는 앱 종류보다 직업 전용 스킬과 공격 모션을 우선합니다.

| 직업 | 무기 | 특징 |
| --- | --- | --- |
| 전사 | 대검 | 체력·공격력 증가, 피해 감소, 스킬 시 방벽 |
| 도적 | 단검 | 공격력 증가, 세 번째 평타 치명타, 네 번째 피격 회피 |
| 마법사 | 마법서 | 스킬 위력 증가, 시작 기력 추가 |
| 힐러 | 스태프 | 회복량 증가, 스킬에 아군 회복, 라운드 자가 회복 |

매 층을 클리어할 때마다 다음 층(2·3·4층…)에서 파티 공통 증강 3개 중 하나를 고릅니다. 평타 강화, 추가 타격, 체력, 스킬 위력, 기력 충전, 흡혈, 라운드 방벽, 회복, 방어력, 치명타, 행동 우선도, 보급의 12종을 지원하며 중첩됩니다. 이후 합류한 동료도 획득한 증강을 이어받습니다.

직업은 앱 종류와 무관하게 무작위로 배정되며, 재시작할 때마다 다시 추첨합니다. 새로 합류하거나 닫았다가 다시 연 앱도 직업을 새로 추첨합니다. 일반 능력치 증강은 자동 모드에서 파티의 직업과 남은 체력을 고려해 고릅니다. 직접 선택하려면 준비 화면에서 **직접 조작 → 탐험 시작** 순서로 시작하세요. 선택 중에는 전투가 멈춥니다. ‘자동 선택으로 계속’을 누르면 직업·증강을 자동으로 선택하고 자동 전투로 전환합니다. 직업과 증강은 이번 탐험에만 적용되며 게임 전환·재시작 시 초기화됩니다.

`node tests/widget-modes-smoke.cjs`로 작은 창 게임 전환을, `node tests/augment-ui-smoke.cjs`로 직업·증강 선택과 자동 선택을 검증합니다.

## 현재 시각과 퇴근 시계

위젯의 행동 안내 대신 한국 시각과 퇴근까지 남은 시간을 초 단위로 표시합니다. 처음에는 기본 퇴근 시각을 지정하지 않습니다. ‘퇴근 시각 입력’을 눌러 직접 시각을 입력하고 저장하세요. 표시를 다시 누르면 변경할 수 있고, 입력을 비운 뒤 저장하면 해제됩니다. 입력한 시각은 다음 실행에도 기억합니다. 게임 일시정지·모드 전환과 무관하게 갱신하며, 오늘의 퇴근 시각이 지나면 ‘퇴근 시간입니다’를 표시합니다.

작은 위젯 상단의 ‘자동 / 수동’ 버튼은 전체 화면의 플레이 방식과 즉시 동기화됩니다. 수동 전투에서는 공격·스킬·방어 버튼이 나타나고, 점프 게임에서는 직접 점프할 수 있습니다. 점프 점수는 흰색 글씨와 검정 테두리로 표시하며 종료 후 다시 도전 화면과 버튼의 배경은 투명합니다.

## 앱 실행 시간에 따른 체력

실행 중인 프로그램은 실제 프로세스 시작 시각을 기준으로 5분마다 최대 체력이 5%씩 증가하며, 실행 시간 보너스는 최대 2배입니다. 직업·증강의 체력 효과와 함께 적용됩니다. 시간 보너스가 늘면 증가분만 회복하고 기존 피해를 초기화하거나 탈락자를 부활시키지 않습니다. 실제 시작 시각을 읽을 수 없는 앱은 처음 감지한 시각부터 계산합니다. 같은 프로그램의 여러 창은 기존처럼 캐릭터 하나로 합치며 마지막 창이 닫히면 제거합니다. 여섯 자리가 찬 경우 추가 앱은 대기하고, 창이 닫혀 빈자리가 생기면 자동 합류합니다. 점프 게임은 기존처럼 한 캐릭터를 조작합니다.

`node tests/six-party-ui-smoke.cjs`로 여섯 앱 합류·귀환, 매 층 증강, 체력 증가, 시계 색과 악당 이름 숨김을 검증합니다.

## 직업별 공격과 표시

전사는 적 앞으로 이동해 대검으로 베고 원래 진형으로 돌아옵니다. 도적은 더 빠르게 접근해 단검으로 연격하고 복귀합니다. 피해는 접근이 끝난 뒤 적용되며 복귀가 끝나야 다음 차례로 넘어갑니다. 마법사는 제자리에서 마법서 주문을, 힐러는 스태프의 빛과 회복 스킬을 사용합니다. 수동 직업 증강은 무작위 3개 중 고르는 방식이며, 자동 배정도 제시된 직업 범위 안에서 무작위로 결정됩니다.

모든 아이콘 아래의 이름은 표시하지 않으며 설정 목록에서는 앱 이름을 확인할 수 있습니다. 시계, 점수, UI와 전투 글자는 흰색 글씨와 검정 테두리로 표시합니다. `node tests/melee-jobs-ui-smoke.cjs`로 재시작·합류·재접속 시 재추첨, 근접 공격의 접근·타격·복귀, 이름 제거와 글자 표시를 검증합니다.

## 글자 가독성

외부 웹폰트 대신 Windows의 맑은 고딕 계열을 사용합니다. 시계·버튼·증강 설명의 크기를 키우고 흰 글씨의 검정 테두리는 얇게 조정했습니다. 캔버스는 실제 화면 배율에 맞춰 렌더링하므로 작은 창이나 고해상도 화면에서도 글자와 아이콘이 흐려지는 것을 줄입니다. `node tests/readability-ui-smoke.cjs`로 1배·2배 배율, 글자 크기와 테두리를 검증합니다.

미리보기 PNG, 테스트용 사용자 프로필과 node_modules는 저장소에서 제외됩니다. 설치 파일 패키징과 배포용 EXE는 아직 포함하지 않습니다.
