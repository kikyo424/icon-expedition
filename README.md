# 아이콘 원정대

실행 중인 Windows 프로그램과 바탕화면 파일의 아이콘으로 즐기는 투명 데스크톱 게임 위젯입니다. 던전, 점프, 배틀, 볼링, 쌓기, 낚시, 농장까지 7개 게임을 자동 또는 수동으로 플레이합니다.

- **작은 투명 창**: 560×355 고정 크기, 항상 위 표시, 위치 이동·저장
- **실제 앱 아이콘**: 앱을 열면 합류하고 마지막 창을 닫으면 귀환
- **선택한 게임만 진행**: 게임 전환·일시정지·최소화·종료 중에는 해당 게임의 진행 중지
- **간단한 조작**: 햄버거 게임 메뉴, 자동·수동 스위치, 재시작·메뉴바 숨김
- **생활 위젯**: 한국 현재 시각과 직접 입력하는 퇴근 시계

## 배포본으로 실행하기

Windows x64용 ZIP 배포본은 Node.js·npm·Git 설치 없이 실행합니다.

1. 배포 ZIP 전체를 원하는 폴더에 압축 해제합니다.
2. 폴더 안의 `IconExpedition.exe`를 실행합니다.
3. 각 PC에서 사용하는 앱과 바탕화면 아이콘이 캐릭터가 됩니다.

EXE 옆의 `resources`, `locales`, DLL 등도 필요한 구성 파일입니다. **EXE만 따로 복사하지 말고 폴더 전체를 전달하세요.** 별도 서버·계정 로그인·관리자 권한 없이 해당 PC에서 동작하며, 게임 저장 데이터도 각 Windows 사용자 프로필에 보관합니다. 다른 사용자의 아이콘이나 저장 데이터는 배포본에 포함하지 않습니다.

현재는 코드 서명이 없는 테스트용 ZIP 버전입니다. 설치 마법사, 단일 파일 실행기, 자동 업데이트는 포함하지 않습니다. 업데이트 시 앱을 종료하고 새 ZIP을 별도 폴더에 압축 해제해 실행합니다. 같은 Windows 사용자와 앱 이름을 사용하면 기존 로컬 저장 데이터를 이어서 사용합니다.

### 배포본 만들기

Windows에서 개발 의존성을 설치한 다음 실행합니다.

```powershell
npm run package:win
```

설치된 Electron 런타임과 실행에 필요한 파일만 복사해 `dist/` 아래에 실행 폴더, ZIP, SHA-256 확인 파일을 생성합니다. 기존 배포본을 덮어쓰지 않도록 빌드마다 별도 폴더를 만듭니다. 테스트·사용자 프로필·미리보기·개인 환경 파일은 포함하지 않습니다. 런타임의 라이선스 고지도 함께 전달합니다.

## 설치와 실행

Windows, Node.js, npm이 필요합니다. 소스를 복제하려면 Git도 필요합니다.

```powershell
git clone https://github.com/kikyo424/icon-expedition.git
cd icon-expedition
npm install
npm start
```

의존성 설치 후에는 `실행.cmd`를 더블클릭해서 실행할 수 있습니다. Electron이 설치되어 있지 않으면 이 파일은 브라우저 체험 화면을 엽니다.

첫 실행은 **실행 중인 앱을 불러와 자동 던전 탐험을 시작**합니다. 참가할 앱이 없으면 앱을 열 때까지 기다립니다. 이후에는 마지막으로 선택한 캐릭터 소스를 기억합니다.

`index.html`을 브라우저로 직접 열면 기본 캐릭터와 직접 추가한 이미지로 7개 게임을 체험할 수 있습니다. 실제 Windows 앱·바탕화면 연결과 네이티브 창 제어는 Electron에서 제공됩니다.

## 작은 창 사용법

위젯은 **560×355** 크기로 고정되며 크기 조절·최대화를 잠급니다. 왼쪽 게임 이름 영역을 끌어 이동하면 위치가 저장됩니다. 전체 설정 창에서는 크기를 조절할 수 있습니다.

| 메뉴바 항목 | 동작 |
| --- | --- |
| ☰ 게임 메뉴 | 7개 게임 선택. 현재 게임은 체크 표시 |
| 수동·자동 스위치 | 현재 게임의 플레이 방식 전환 |
| 공격·스킬·방어 | 수동 던전·배틀에서 표시되는 전투 버튼 |
| 위쪽 꺾쇠 | 메뉴바 숨기기 |
| 원형 화살표 | 현재 게임을 처음부터 다시 시작 |
| 재생·일시정지 | 게임 시작, 진행 중 일시정지, 이어서 재생 |
| 창·화살표 아이콘 | 전체 설정 창 펼치기 |
| × | 앱 종료 |

메뉴바를 숨기면 **오른쪽 위의 아래쪽 꺾쇠 버튼**으로 다시 펼칩니다. 메뉴바를 숨겨도 게임은 계속 진행되며 게임 화면의 위치와 크기는 유지됩니다.

게임 메뉴는 항목 선택, 바깥 클릭, Esc로 닫습니다. 키보드로는 위아래 방향키·Home·End로 이동하고 Enter로 선택할 수 있습니다. 시작 화면과 시작 버튼도 배경이 투명합니다. 메뉴가 닫힌 작은 창에서 Esc를 누르면 전체 설정 화면으로 돌아옵니다.

작은 창에서 던전 탐험은 이어서 진행합니다. 나머지 6개 게임은 게임을 선택하거나 전체 설정에서 작은 창으로 전환할 때 새 판의 준비 화면을 띄우며, 시작 버튼을 눌러야 진행합니다. 작은 창의 다시 시작 버튼도 던전은 바로 새 탐험을 시작하고 나머지는 준비 화면으로 돌아갑니다. 자동·수동 설정과 최고 기록, 낚시 수집 데이터는 유지합니다. 농장에서 다시 시작 버튼을 누르면 밭·선택 작물·코인·수확 수를 초기화해 밭 1칸과 벼부터 시작합니다. 코인은 낚시와 공유하므로 이 초기화 시 공유 코인 잔액도 0이 됩니다. 던전의 층·직업·증강, 볼링의 투구·점수, 쌓기의 블록 등 이번 판의 상태는 초기화합니다.

전체 설정 화면의 ‘다시 시작’은 참가자와 설정을 다시 고를 수 있는 준비 화면으로 돌아갑니다. ‘투명 위젯’을 누르면 던전은 이어서 진행하고, 나머지 게임은 새 판의 시작을 기다립니다.

### 글자와 화면

- 게임 화면과 창 테두리는 투명하며, 열린 메뉴에는 읽기 쉬운 진한 배경을 사용합니다.
- 메뉴는 12px 글자, 전체 게임 이름, 현재 선택 체크, 32px 높이의 항목으로 구성합니다.
- 시계와 자동·수동 스위치에는 반투명 바탕을 사용합니다.
- Windows의 맑은 고딕 계열과 화면 배율에 맞춘 캔버스 렌더링을 사용합니다.
- 투명 게임 화면의 글자는 흰색과 얇은 검정 테두리로 표시합니다. 진한 메뉴·시계 바탕 위에서는 글자 테두리를 제거합니다.
- 캐릭터와 악당 아래에는 이름을 표시하지 않습니다. 이름은 설정 목록에서 확인합니다.

## 캐릭터 소스

전체 설정 화면에서 **실행 중인 앱 / 바탕화면 파일**을 선택합니다.

### 실행 중인 앱

일반 창이 있는 프로그램의 실제 아이콘과 제품 이름을 읽습니다. 같은 실행 파일의 여러 창은 한 캐릭터로 합칩니다.

- 새 앱은 빈 자리에 자동 합류합니다. 정원이 차면 대기합니다.
- 마지막 창을 닫으면 캐릭터가 제거되고, 빈자리에 대기 앱이 합류합니다.
- 참가자를 클릭해 제외하거나 다시 포함할 수 있습니다. 제외 목록과 파티 우선 선택은 저장합니다.
- 현재 사용하는 앱은 발밑 테두리로 구분합니다.
- GPT·Codex도 참가하며, 아이콘 원정대 자체와 Electron·시스템·도구 창은 제외합니다.
- 목록 갱신에는 몇 초가 걸릴 수 있습니다. 전체 설정에서 수동 새로고침도 가능합니다.
- 일부 보호된 프로그램이나 구형 UWP 호스트는 수집되지 않을 수 있습니다.

**아이콘 원정대를 실행한 시간**을 기준으로 실행 중인 앱 캐릭터에 5분마다 최대 체력 5% 증가, 시간 보너스 최대 2배를 적용합니다. 외부 프로그램을 먼저 오래 켜두었는지는 영향을 주지 않습니다. 원정대를 종료하고 다시 켜면 실행 시간과 보너스가 0부터 시작하며, 게임만 다시 시작하거나 전환할 때에는 세션 시간이 유지됩니다. 큰 설정 화면의 배틀 참가자 목록에서 실행 경과 시간과 각 캐릭터의 체력 보너스를 확인할 수 있습니다. 직업·증강 효과와 함께 적용하며, 증가분만 회복합니다. 갱신으로 기존 피해를 초기화하거나 탈락자를 부활시키지 않습니다.

### 바탕화면 파일

Windows Shell에서 바탕화면 항목의 표시 이름, 개별 아이콘, 캐시된 미리보기를 읽습니다. 표시 설정이 켜진 휴지통 같은 시스템 아이콘도 포함할 수 있습니다. Shell 조회가 실패하면 사용자·공용 바탕화면 파일을 읽는 대체 경로를 사용합니다.

폴더·바로가기·이미지·미디어·압축 파일·일반 문서 종류에 따라 역할과 능력치가 달라집니다. 파일은 이동하거나 실행하지 않습니다. 원본 아이콘을 얻지 못한 항목은 기본 표시로 대체될 수 있습니다.

‘바탕화면 새로고침’으로 목록과 아이콘 크기를 다시 읽습니다. 이미지 파일을 캐릭터로 직접 추가할 수도 있습니다. 직접 추가한 이미지는 앱 종료 시 초기화됩니다.

### 게임별 참가 정원

| 게임 | 실행 중인 앱 | 바탕화면 파일 |
| --- | --- | --- |
| 던전 | 최대 6명 | 최대 3명 |
| 점프 | 1명 | 1명 |
| 배틀 | 2~6명 | 2~4명 |
| 볼링·쌓기 | 최대 6명 | 최대 4명 |
| 낚시 | 1명 | 1명 |
| 농장 | 최대 6명 | 최대 3명 |

볼링은 투구마다, 쌓기는 새 블록마다 참가 아이콘을 순서대로 사용합니다. 농장 화면에는 최대 3명의 작업 아이콘을 표시합니다. 캐릭터의 기본 아이콘 크기는 Windows 바탕화면 설정과 화면 배율을 반영합니다. 타워 블록 표면에 찍는 아이콘은 블록 안에 맞춰 축소합니다.

## 게임과 조작

| 게임 | 내용 | 수동 조작 |
| --- | --- | --- |
| 던전 탐험 | 파티가 층을 오르는 턴제 전투. 5층마다 보스 | 내 차례에 Space 공격, Q 스킬, E 방어 |
| 아이콘 점프 | 장애물을 넘는 무한 달리기 | Space·위 방향키·W 또는 화면 클릭으로 점프 |
| 배틀 아레나 | 중앙에 몰려들어 싸우는 실시간 개인전. 마지막 생존자 우승 | 첫 참가자를 WASD·방향키로 이동, Space 공격, Q 스킬, E 방어 |
| 아이콘 볼링 | 아이콘 공으로 핀 10개 쓰러뜨리기. 10회 투구 합산 | 좌클릭을 누른 채 마우스로 조준하고 놓으면 투구 |
| 아이콘 타워 | 무게중심에 따라 기울고 떨어지는 블록 쌓기 | 좌우로 왕복하는 블록을 Space·클릭으로 낙하(회전 없음) |
| 아이콘 낚시 | 입질과 장력을 맞춰 물고기·보물 수집 | Space·클릭으로 던지기와 입질 잡기, 누르면 당기고 놓으면 장력 감소 |
| 작은 농장 | 아이콘이 도구를 들고 밭을 가꾸며 벼·감자·당근·토마토·배추·딸기 수확 | 밭 클릭 또는 좌우·A/D 선택 후 Space 관리, 1~6 작물 선택, Q 순환 |

자동 모드에서는 각 게임이 조준·이동·전투·낚기·농장 관리를 수행합니다. 작은 창에서는 게임을 바꾼 뒤 시작 버튼으로 새 판을 시작합니다(던전 탐험 제외). 낚시·농장의 누적 데이터와 기록은 유지합니다.

### 던전 직업·증강

탐험 시작 시 각 동료에게 **무작위 직업 증강 3개**가 제시됩니다. 수동 모드는 하나를 고르고, 자동 모드는 제시된 직업 중 무작위로 배정합니다. 앱 종류로 직업을 고정하지 않습니다.

| 직업 | 표시 무기 | 특징 |
| --- | --- | --- |
| 전사 | 대검 | 체력·공격력 증가, 피해 감소, 근접 공격과 방벽 |
| 도적 | 단검 | 빠른 접근·연격, 치명타와 회피 |
| 마법사 | 마법서 | 주문 공격, 스킬 위력과 시작 기력 증가 |
| 힐러 | 스태프 | 회복량 증가, 아군 회복과 라운드 회복 |

전사·도적은 적 앞으로 이동해 타격하고 원래 진형으로 돌아옵니다. 마법사·힐러는 제자리에서 직업 전용 효과를 사용합니다. 아이콘 옆에 무기를 표시하며 직업 이름 배지는 표시하지 않습니다.

매 층을 클리어해 다음 층에 들어가면 **파티 공통 증강 3개 중 하나**를 고릅니다. 평타 강화, 추가 타격, 체력, 스킬 위력, 기력, 흡혈, 방벽, 회복, 방어력, 치명타, 행동 우선도, 보급의 12종을 지원하며 중첩됩니다. 이후 합류한 동료도 파티 증강을 이어받습니다.

자동 모드는 일반 증강을 파티 직업과 남은 체력에 따라 선택합니다. 직접 고르려면 수동 모드로 시작하세요. 선택 중 전투는 멈추며 ‘자동 선택으로 계속’으로 자동 전투에 돌아갈 수 있습니다.

재시작하면 직업을 다시 추첨합니다. 새로 합류하거나 닫았다 다시 연 앱도 새 직업을 받습니다. 직업과 증강은 이번 탐험에만 적용됩니다.

### 전투 스킬과 악당

던전·배틀의 기본 공격·방어는 기력을 충전하고 스킬은 기력 2를 사용합니다. 자동 모드에서도 스킬을 사용합니다. 직업이 없는 아이콘은 앱·파일 종류에 따른 고유 공격 표현과 스킬을 사용합니다. 브라우저의 다중 공격, 문서의 방벽, 메신저의 회복, 코드 편집기의 연쇄 공격 등을 구분합니다.

던전 악당은 슬라임, 보고서, 캘린더, 업무 가방, 프린터, 야근 시계에서 여러 종류를 선택할 수 있습니다. 직접 악당 이미지 추가도 지원합니다(파일당 3MB 이하). 진행 중 선택 변경은 다음 층부터 적용됩니다. 기본 악당 선택은 저장하고 직접 추가한 악당 이미지는 종료 시 초기화합니다.

### 볼링·쌓기 규칙

볼링은 **10번 투구에서 쓰러뜨린 핀 수를 합산**하며 최대 100점입니다. 핀끼리의 연쇄 충돌을 계산합니다. 일반 볼링의 스페어·스트라이크 보너스 규칙은 적용하지 않습니다. 완료한 10회 투구의 최고 기록은 자동·수동으로 나누어 저장합니다. 한 판에서 자동 진행이 한 번이라도 사용되면 자동 기록으로 분류하며, 방식 구분이 없던 과거 기록은 수동 기록으로 이전하지 않습니다. 화면 오른쪽 점수판에 자동·수동 최고 점수와 남은 투구 수, 힘 게이지, 투구 방향, 총점과 1~10회차 점수를 모두 표시합니다. 좌클릭을 누르면 힘이 0%부터 100%까지 왕복하고, 좌클릭을 누른 채 좌우로 이동하면 공 위치가 따라갑니다. 충전 중 방향선도 좌우로 왕복합니다. 우클릭하면 방향만 고정되고 다시 우클릭하면 왕복을 재개합니다. 힘 게이지와 공 위치는 방향 고정 중에도 조절됩니다. 이동 중에도 힘 게이지는 초기화되지 않습니다. 버튼을 놓는 순간의 힘과 방향으로 발사합니다. 창 밖에서 버튼을 놓아도 중복 발사하지 않으며, 일시정지·창 전환 시 충전을 취소합니다. 레인에서 공을 중앙으로 자동 유도하지 않으며, 방향·힘·핀 충돌에 따라 결과가 달라집니다.

쌓기는 I·O·T·L·J·S·Z의 7가지 테트로미노 모양과 무작위 특수 블록을 사용합니다. 모양은 고정이며 회전 조작은 없습니다. 빈 모양 부분을 제외한 실제 셀로 충돌과 무게중심을 계산합니다. 덩굴은 놓인 자리에서 옆벽으로 줄기를 뻗어 고정되며 어떤 방향으로 치우쳐도 기울지 않고 아래 받침이 무너져도 유지됩니다. 독립 받침은 공중에 고정되어 아래 탑과 무관한 바닥이 됩니다. 돌은 무겁고 구름은 가벼워 전체 무게중심에 영향을 줍니다. 대기 블록은 자동으로 좌우 왕복하며 Space 또는 클릭한 순간의 위치에서 떨어집니다. 클릭 위치로 블록을 순간이동시키지 않습니다. 각 받침에 실린 위쪽 블록 전체의 무게중심을 계산하며, 한쪽으로 치우치면 기울고 위의 블록들도 함께 무너집니다. 낙하 가속도는 이전보다 약 46% 높였습니다. 높이에 따라 카메라가 이동합니다. 블록을 3개 놓치면 종료합니다. 대기 블록은 탑이 높아져도 화면 안에서 볼 수 있도록 배치합니다.

### 낚시·농장 저장과 코인

낚시에서 피라미, 붕어, 황금 잉어, 보물 상자를 얻습니다. 희귀할수록 입질 시간이 짧고 적정 장력 구간이 좁습니다. 구간이 움직이고 물고기가 불규칙하게 저항하며, 18초 안에 끌어올려야 합니다. 자동 모드도 반응 지연이 있어 실패할 수 있습니다. 수집 수와 코인을 저장하며, **낚시와 농장이 코인을 공유**합니다.

| 작물 | 해금 조건 | 기본 씨앗 값 | 수확 보상 | 성장 시간 |
| --- | --- | --- | --- | --- |
| 벼 | 밭 1칸 | 무료 | 1코인 | 15초 |
| 감자 | 밭 2칸 | 1코인 | 8코인 | 30초 |
| 당근 | 밭 3칸 | 2코인 | 15코인 | 45초 |
| 토마토 | 밭 4칸 | 4코인 | 25코인 | 65초 |
| 배추 | 밭 5칸 | 7코인 | 40코인 | 85초 |
| 딸기 | 밭 6칸 | 12코인 | 60코인 | 110초 |

새 농장은 밭 1칸, 코인 0개로 시작합니다. 벼는 무료로 심고 1코인씩 벌 수 있습니다. 다음 밭을 클릭하면 5·15·40·100·250코인을 내고 순서대로 확장합니다. 벼 외의 씨앗은 심을 때마다 기본 가격에 ‘보유 밭 수 − 1’을 더한 값을 지불합니다. 현재 씨앗 값과 다음 밭 가격은 화면에 표시합니다.

작물을 선택하고 밭을 클릭하면 씨앗 구매와 파종을 함께 수행합니다. 물을 주면 총 성장 시간이 35% 줄어듭니다. 아이콘은 괭이·물뿌리개·낫으로 작업합니다. 자동 모드는 수확·물주기·파종을 반복하고, 여유 코인으로 밭을 확장합니다. 선택한 씨앗을 살 돈이 부족하면 무료 벼를 심어 진행을 계속합니다.

작물 선택·코인·밭·성장은 저장됩니다. 기존 저장본의 코인과 재배 중인 작물을 유지하는 이전 처리를 포함합니다. 새 농장에만 밭 1칸 규칙을 적용하므로 기존 재배 데이터가 삭제되지는 않습니다.

## 게임 진행 범위와 저장

**현재 선택한 게임 하나만 진행합니다.** 다른 게임으로 전환하면 이전 판은 더 이상 진행하지 않습니다. 일시정지, 창 최소화·숨김, 앱 종료 중에는 전투·낚시·농장 성장이 진행하지 않습니다. 앱을 다시 켜도 꺼둔 시간을 보상이나 성장 시간으로 더하지 않습니다.

다른 프로그램을 클릭해 작업하더라도 위젯 창이 열려 있으면 자동 플레이를 계속합니다. **메뉴바 숨김은 창 숨김과 다르므로 게임을 멈추지 않습니다.**

| 저장되는 항목 | 이번 판 또는 실행에만 유지되는 항목 |
| --- | --- |
| 던전·점프·볼링·쌓기 최고 기록, 배틀 완료 횟수 | 진행 중인 전투, 점프, 볼링, 쌓기 판 |
| 낚시 수집 수·코인, 농장 밭·성장 진행·선택 작물·수확 수 | 던전 직업·증강 |
| 캐릭터 소스, 실행 앱 제외 목록, 파티 우선 선택 | 직접 추가한 캐릭터·악당 이미지 |
| 기본 악당 선택, 퇴근 시각, 위젯 위치 | 메뉴바 접힘 상태, 게임별 자동·수동 선택 |

진행 데이터는 이 기기의 앱 프로필에 보관합니다. 브라우저 체험 데이터와 Electron 앱 데이터는 서로 공유하지 않습니다. 농장 성장 시간은 주기적으로 저장하고, 게임 전환·창 상태 변경·종료 시에도 저장합니다.

## 현재 시각과 퇴근 시계

현재 시각은 호스트 시간대와 관계없이 **한국 시각(Asia/Seoul)**으로 표시합니다. 퇴근 시각은 기본값 없이 직접 입력합니다.

1. ‘퇴근 시각 입력’ 또는 퇴근 표시를 클릭합니다.
2. 원하는 시각을 입력하고 저장합니다.
3. 표시를 다시 클릭하면 수정할 수 있습니다. 입력을 비우고 저장하면 해제됩니다.

퇴근 시각 전에는 남은 시간을 초 단위로 표시하고, 오늘의 퇴근 시각이 지나면 **‘퇴근’**을 표시합니다. 시계는 게임 선택과 일시정지와 별도로 갱신합니다.

## 검증

기본 문법·단위 테스트:

```powershell
npm run check
npm test
```

단위 테스트는 Node.js 기본 테스트 러너를 사용하며, 현재 84개입니다. 전투·배틀·직업·증강·파티·농장 성장 및 저장·시계 등을 검증합니다.

브라우저 시나리오에는 Playwright와 설치된 Google Chrome이 필요합니다. Playwright가 없는 개발 환경에서는 다음과 같이 테스트용으로 설치할 수 있습니다.

```powershell
npm install --no-save --package-lock=false playwright
node tests/widget-menu-smoke.cjs
node tests/widget-toolbar-smoke.cjs
node tests/readability-ui-smoke.cjs
node tests/active-game-smoke.cjs
node tests/leisure-ui-smoke.cjs
node tests/live-apps-smoke.cjs
node tests/turn-ui-smoke.cjs
node tests/brawl-ui-smoke.cjs
```

| 검증 파일 | 주요 범위 |
| --- | --- |
| `widget-menu-smoke.cjs` | 7개 게임 메뉴, 키보드 탐색, 자동·수동 스위치 |
| `widget-toolbar-smoke.cjs` | 재시작, 메뉴바 숨김·복원, 재생·확대 아이콘 |

| `leisure-ui-smoke.cjs` | 새 게임 4종 조작, 낚시 보상, 농장 저장·수확 |

## 현재 범위와 다음 개선 후보

소스 실행과 Windows x64 ZIP 배포를 지원하며, 설치형 EXE·단일 파일 실행기·자동 업데이트는 포함하지 않습니다. 게임을 바꾸거나 앱을 종료할 때 진행 중인 판을 저장해 그대로 이어 하는 기능도 제공하지 않습니다. 농장 성장·수집 데이터는 위 저장 규칙을 따릅니다.

다음 개선 후보는 작은 창의 조작 도움말, ㄴ·ㅗ 형태 등 쌓기 블록 다양화, 설치 마법사·코드 서명을 갖춘 배포입니다. 현재 구현된 기능과 구분하기 위해 이 항목들은 계획으로만 기록합니다.
