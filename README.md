# 아이콘 원정대

실행 중인 Windows 프로그램과 바탕화면 파일의 아이콘으로 즐기는 투명 데스크톱 게임 위젯입니다. 던전, 점프, 배틀, 볼링, 쌓기, 낚시, 농장까지 7개 게임을 자동 또는 수동으로 플레이합니다.

- **작은 투명 창**: 560×355 고정 크기, 항상 위 표시, 위치 이동·저장
- **실제 앱 아이콘**: 앱을 열면 합류하고 마지막 창을 닫으면 귀환
- **선택한 게임만 진행**: 게임 전환·일시정지·최소화·종료 중에는 해당 게임의 진행 중지
- **간단한 조작**: 햄버거 게임 메뉴, 자동·수동 스위치, 재시작·메뉴바 숨김
- **생활 위젯**: 한국 현재 시각과 직접 입력하는 퇴근 시계

## 설치와 실행

Windows, Node.js, npm이 필요합니다. 소스를 복제하려면 Git도 필요합니다.

```powershell
git clone https://github.com/kikyo424/icon-expedition.git
cd icon-expedition
npm install
npm start
```

의존성 설치 후에는 `실행.cmd`를 더블클릭해서 실행할 수 있습니다. Electron이 설치되어 있지 않으면 이 파일은 브라우저 체험 화면을 엽니다.

첫 실행은 **실행 중인 앱을 불러와 자동 던전 탐험을 시작**합니다. 참가할 앱이 없으면 앱을 열 때까지 기다립니다. 이후에는 마지막으로 선택한 캐릭터 소스를 기억합니다.

`index.html`을 브라우저로 직접 열면 기본 캐릭터와 직접 추가한 이미지로 7개 게임을 체험할 수 있습니다. 실제 Windows 앱·바탕화면 연결과 네이티브 창 제어는 Electron에서 제공됩니다.

## 작은 창 사용법

위젯은 **560×355** 크기로 고정되며 크기 조절·최대화를 잠급니다. 왼쪽 게임 이름 영역을 끌어 이동하면 위치가 저장됩니다. 전체 설정 창에서는 크기를 조절할 수 있습니다.

| 메뉴바 항목 | 동작 |
| --- | --- |
| ☰ 게임 메뉴 | 7개 게임 선택. 현재 게임은 체크 표시 |
| 수동·자동 스위치 | 현재 게임의 플레이 방식 전환 |
| 공격·스킬·방어 | 수동 던전·배틀에서 표시되는 전투 버튼 |
| 위쪽 꺾쇠 | 메뉴바 숨기기 |
| 원형 화살표 | 현재 게임을 처음부터 다시 시작 |
| 재생·일시정지 | 게임 시작, 진행 중 일시정지, 이어서 재생 |
| 창·화살표 아이콘 | 전체 설정 창 펼치기 |
| × | 앱 종료 |

메뉴바를 숨기면 **오른쪽 위의 아래쪽 꺾쇠 버튼**으로 다시 펼칩니다. 메뉴바를 숨겨도 게임은 계속 진행되며 게임 화면의 위치와 크기는 유지됩니다.

게임 메뉴는 항목 선택, 바깥 클릭, Esc로 닫습니다. 키보드로는 위아래 방향키·Home·End로 이동하고 Enter로 선택할 수 있습니다. 메뉴가 닫힌 작은 창에서 Esc를 누르면 전체 설정 화면으로 돌아옵니다.

작은 창의 다시 시작 버튼은 준비 화면을 거치지 않고 현재 게임을 새로 시작합니다. 자동·수동 설정과 최고 기록, 낚시·농장 저장 데이터는 유지합니다. 던전의 층·직업·증강, 볼링의 투구·점수, 쌓기의 블록 등 이번 판의 상태는 초기화합니다.

전체 설정 화면의 ‘다시 시작’은 참가자와 설정을 다시 고를 수 있는 준비 화면으로 돌아갑니다. ‘투명 위젯’을 누르면 진행 중인 게임을 작은 창에서 이어갑니다.

### 글자와 화면

- 게임 화면과 창 테두리는 투명하며, 열린 메뉴에는 읽기 쉬운 진한 배경을 사용합니다.
- 메뉴는 12px 글자, 전체 게임 이름, 현재 선택 체크, 32px 높이의 항목으로 구성합니다.
- 시계와 자동·수동 스위치에는 반투명 바탕을 사용합니다.
- Windows의 맑은 고딕 계열과 화면 배율에 맞춘 캔버스 렌더링을 사용합니다.
- 투명 게임 화면의 글자는 흰색과 얇은 검정 테두리로 표시합니다. 진한 메뉴·시계 바탕 위에서는 글자 테두리를 제거합니다.
- 캐릭터와 악당 아래에는 이름을 표시하지 않습니다. 이름은 설정 목록에서 확인합니다.

## 캐릭터 소스

전체 설정 화면에서 **실행 중인 앱 / 바탕화면 파일**을 선택합니다.

### 실행 중인 앱

일반 창이 있는 프로그램의 실제 아이콘과 제품 이름을 읽습니다. 같은 실행 파일의 여러 창은 한 캐릭터로 합칩니다.

- 새 앱은 빈 자리에 자동 합류합니다. 정원이 차면 대기합니다.
- 마지막 창을 닫으면 캐릭터가 제거되고, 빈자리에 대기 앱이 합류합니다.
- 참가자를 클릭해 제외하거나 다시 포함할 수 있습니다. 제외 목록과 파티 우선 선택은 저장합니다.
- 현재 사용하는 앱은 발밑 테두리로 구분합니다.
- GPT·Codex도 참가하며, 아이콘 원정대 자체와 Electron·시스템·도구 창은 제외합니다.
- 목록 갱신에는 몇 초가 걸릴 수 있습니다. 전체 설정에서 수동 새로고침도 가능합니다.
- 일부 보호된 프로그램이나 구형 UWP 호스트는 수집되지 않을 수 있습니다.

앱의 실제 실행 시간에 따라 **5분마다 최대 체력 5% 증가, 시간 보너스 최대 2배**를 적용합니다. 직업·증강 효과와 함께 적용하며, 증가분만 회복합니다. 갱신으로 기존 피해를 초기화하거나 탈락자를 부활시키지 않습니다. 실행 시작 시각을 읽을 수 없으면 처음 감지한 시각부터 계산합니다.

### 바탕화면 파일

Windows Shell에서 바탕화면 항목의 표시 이름, 개별 아이콘, 캐시된 미리보기를 읽습니다. 표시 설정이 켜진 휴지통 같은 시스템 아이콘도 포함할 수 있습니다. Shell 조회가 실패하면 사용자·공용 바탕화면 파일을 읽는 대체 경로를 사용합니다.

폴더·바로가기·이미지·미디어·압축 파일·일반 문서 종류에 따라 역할과 능력치가 달라집니다. 파일은 이동하거나 실행하지 않습니다. 원본 아이콘을 얻지 못한 항목은 기본 표시로 대체될 수 있습니다.

‘바탕화면 새로고침’으로 목록과 아이콘 크기를 다시 읽습니다. 이미지 파일을 캐릭터로 직접 추가할 수도 있습니다. 직접 추가한 이미지는 앱 종료 시 초기화됩니다.

### 게임별 참가 정원

| 게임 | 실행 중인 앱 | 바탕화면 파일 |
| --- | --- | --- |
| 던전 | 최대 6명 | 최대 3명 |
| 점프 | 1명 | 1명 |
| 배틀 | 2~6명 | 2~4명 |
| 볼링·쌓기·낚시 | 각 1명 | 각 1명 |
| 농장 | 최대 6명 | 최대 3명 |

농장 화면에는 최대 3명의 작업 아이콘을 표시합니다. 캐릭터의 기본 아이콘 크기는 Windows 바탕화면 설정과 화면 배율을 반영합니다. 타워 블록 표면에 찍는 아이콘은 블록 안에 맞춰 축소합니다.

## 게임과 조작

| 게임 | 내용 | 수동 조작 |
| --- | --- | --- |
| 던전 탐험 | 파티가 층을 오르는 턴제 전투. 5층마다 보스 | 내 차례에 Space 공격, Q 스킬, E 방어 |
| 아이콘 점프 | 장애물을 넘는 무한 달리기 | Space·위 방향키·W 또는 화면 클릭으로 점프 |
| 배틀 아레나 | 중앙에 몰려들어 싸우는 실시간 개인전. 마지막 생존자 우승 | 첫 참가자를 WASD·방향키로 이동, Space 공격, Q 스킬, E 방어 |
| 아이콘 볼링 | 아이콘 공으로 핀 10개 쓰러뜨리기. 10회 투구 합산 | 좌우 조준, 위아래 힘 조절, Space 투구 또는 레인 클릭 |
| 아이콘 타워 | 무게중심에 따라 기울고 떨어지는 블록 쌓기 | 좌우·A/D 이동, Q 회전, Space 낙하 또는 위치 클릭 |
| 아이콘 낚시 | 입질과 장력을 맞춰 물고기·보물 수집 | Space·클릭으로 던지기와 입질 잡기, 누르면 당기고 놓으면 장력 감소 |
| 작은 농장 | 당근·토마토·호박을 심고 수확 | 밭 클릭 또는 좌우·A/D 선택 후 Space 관리, 1·2·3 작물 선택, Q 순환 |

자동 모드에서는 각 게임이 조준·이동·전투·낚기·농장 관리를 수행합니다. 게임을 바꾸면 새 판으로 시작합니다. 낚시·농장의 누적 데이터와 기록은 유지합니다.

### 던전 직업·증강

탐험 시작 시 각 동료에게 **무작위 직업 증강 3개**가 제시됩니다. 수동 모드는 하나를 고르고, 자동 모드는 제시된 직업 중 무작위로 배정합니다. 앱 종류로 직업을 고정하지 않습니다.

| 직업 | 표시 무기 | 특징 |
| --- | --- | --- |
| 전사 | 대검 | 체력·공격력 증가, 피해 감소, 근접 공격과 방벽 |
| 도적 | 단검 | 빠른 접근·연격, 치명타와 회피 |
| 마법사 | 마법서 | 주문 공격, 스킬 위력과 시작 기력 증가 |
| 힐러 | 스태프 | 회복량 증가, 아군 회복과 라운드 회복 |

전사·도적은 적 앞으로 이동해 타격하고 원래 진형으로 돌아옵니다. 마법사·힐러는 제자리에서 직업 전용 효과를 사용합니다. 아이콘 옆에 무기를 표시하며 직업 이름 배지는 표시하지 않습니다.

매 층을 클리어해 다음 층에 들어가면 **파티 공통 증강 3개 중 하나**를 고릅니다. 평타 강화, 추가 타격, 체력, 스킬 위력, 기력, 흡혈, 방벽, 회복, 방어력, 치명타, 행동 우선도, 보급의 12종을 지원하며 중첩됩니다. 이후 합류한 동료도 파티 증강을 이어받습니다.

자동 모드는 일반 증강을 파티 직업과 남은 체력에 따라 선택합니다. 직접 고르려면 수동 모드로 시작하세요. 선택 중 전투는 멈추며 ‘자동 선택으로 계속’으로 자동 전투에 돌아갈 수 있습니다.

재시작하면 직업을 다시 추첨합니다. 새로 합류하거나 닫았다 다시 연 앱도 새 직업을 받습니다. 직업과 증강은 이번 탐험에만 적용됩니다.

### 전투 스킬과 악당

던전·배틀의 기본 공격·방어는 기력을 충전하고 스킬은 기력 2를 사용합니다. 자동 모드에서도 스킬을 사용합니다. 직업이 없는 아이콘은 앱·파일 종류에 따른 고유 공격 표현과 스킬을 사용합니다. 브라우저의 다중 공격, 문서의 방벽, 메신저의 회복, 코드 편집기의 연쇄 공격 등을 구분합니다.

던전 악당은 슬라임, 보고서, 캘린더, 업무 가방, 프린터, 야근 시계에서 여러 종류를 선택할 수 있습니다. 직접 악당 이미지 추가도 지원합니다(파일당 3MB 이하). 진행 중 선택 변경은 다음 층부터 적용됩니다. 기본 악당 선택은 저장하고 직접 추가한 악당 이미지는 종료 시 초기화합니다.

### 볼링·쌓기 규칙

볼링은 **10번 투구에서 쓰러뜨린 핀 수를 합산**하며 최대 100점입니다. 핀끼리의 연쇄 충돌을 계산합니다. 일반 볼링의 스페어·스트라이크 보너스 규칙은 적용하지 않습니다.

쌓기는 크기가 다른 직사각형 블록을 사용합니다. 받침 밖으로 무게중심이 벗어나면 기울고 떨어지며, 높이에 따라 카메라가 이동합니다. 블록을 3개 놓치면 종료합니다. 대기 블록은 회전하거나 탑이 높아져도 화면 안에서 볼 수 있도록 배치합니다.

### 낚시·농장 저장과 코인

낚시에서 피라미, 붕어, 황금 잉어, 보물 상자를 얻습니다. 수집 수와 코인을 저장하며, **낚시와 농장이 코인을 공유**합니다.

| 작물 | 씨앗 비용 | 수확 보상 | 기본 성장 시간 |
| --- | --- | --- | --- |
| 당근 | 2코인 | 5코인 | 45초 |
| 토마토 | 4코인 | 10코인 | 90초 |
| 호박 | 7코인 | 18코인 | 150초 |

밭은 6칸입니다. 빈 밭에서 심고, 자라는 밭에 물을 주며, 익은 밭에서 수확합니다. 물을 주면 총 성장 시간이 35% 줄어듭니다. 밭 사이 빈 공간은 클릭해도 작동하지 않습니다.

선택한 작물은 게임 전환·재시작·앱 재실행 후에도 유지합니다. 자동 농장은 현재 고른 작물로 수확·물주기·파종을 반복합니다. 씨앗 코인이 부족하면 낚시로 코인을 얻을 수 있습니다.

## 게임 진행 범위와 저장

**현재 선택한 게임 하나만 진행합니다.** 다른 게임으로 전환하면 이전 판은 더 이상 진행하지 않습니다. 일시정지, 창 최소화·숨김, 앱 종료 중에는 전투·낚시·농장 성장이 진행하지 않습니다. 앱을 다시 켜도 꺼둔 시간을 보상이나 성장 시간으로 더하지 않습니다.

다른 프로그램을 클릭해 작업하더라도 위젯 창이 열려 있으면 자동 플레이를 계속합니다. **메뉴바 숨김은 창 숨김과 다르므로 게임을 멈추지 않습니다.**

| 저장되는 항목 | 이번 판 또는 실행에만 유지되는 항목 |
| --- | --- |
| 던전·점프·볼링·쌓기 최고 기록, 배틀 완료 횟수 | 진행 중인 전투, 점프, 볼링, 쌓기 판 |
| 낚시 수집 수·코인, 농장 밭·성장 진행·선택 작물·수확 수 | 던전 직업·증강 |
| 캐릭터 소스, 실행 앱 제외 목록, 파티 우선 선택 | 직접 추가한 캐릭터·악당 이미지 |
| 기본 악당 선택, 퇴근 시각, 위젯 위치 | 메뉴바 접힘 상태, 게임별 자동·수동 선택 |

진행 데이터는 이 기기의 앱 프로필에 보관합니다. 브라우저 체험 데이터와 Electron 앱 데이터는 서로 공유하지 않습니다. 농장 성장 시간은 주기적으로 저장하고, 게임 전환·창 상태 변경·종료 시에도 저장합니다.

## 현재 시각과 퇴근 시계

현재 시각은 호스트 시간대와 관계없이 **한국 시각(Asia/Seoul)**으로 표시합니다. 퇴근 시각은 기본값 없이 직접 입력합니다.

1. ‘퇴근 시각 입력’ 또는 퇴근 표시를 클릭합니다.
2. 원하는 시각을 입력하고 저장합니다.
3. 표시를 다시 클릭하면 수정할 수 있습니다. 입력을 비우고 저장하면 해제됩니다.

퇴근 시각 전에는 남은 시간을 초 단위로 표시하고, 오늘의 퇴근 시각이 지나면 **‘퇴근’**을 표시합니다. 시계는 게임 선택과 일시정지와 별도로 갱신합니다.

## 검증

기본 문법·단위 테스트:

```powershell
npm run check
npm test
```

단위 테스트는 Node.js 기본 테스트 러너를 사용하며, 현재 55개입니다. 전투·배틀·직업·증강·파티·농장 성장 및 저장·시계 등을 검증합니다.

브라우저 시나리오에는 Playwright와 설치된 Google Chrome이 필요합니다. Playwright가 없는 개발 환경에서는 다음과 같이 테스트용으로 설치할 수 있습니다.

```powershell
npm install --no-save --package-lock=false playwright
node tests/widget-menu-smoke.cjs
node tests/widget-toolbar-smoke.cjs
node tests/readability-ui-smoke.cjs
node tests/active-game-smoke.cjs
node tests/leisure-ui-smoke.cjs
node tests/live-apps-smoke.cjs
node tests/turn-ui-smoke.cjs
node tests/brawl-ui-smoke.cjs
```

| 검증 파일 | 주요 범위 |
| --- | --- |
| `widget-menu-smoke.cjs` | 7개 게임 메뉴, 키보드 탐색, 자동·수동 스위치 |
| `widget-toolbar-smoke.cjs` | 재시작, 메뉴바 숨김·복원, 재생·확대 아이콘 |
| `readability-ui-smoke.cjs` | 1배·2배 화면 배율, 글자 크기, 메뉴 범위·대비 |
| `active-game-smoke.cjs` | 현재 게임만 진행, 일시정지·숨김·재실행 후 농장 시간 유지 |
| `leisure-ui-smoke.cjs` | 새 게임 4종 조작, 낚시 보상, 농장 저장·수확 |
| `live-apps-smoke.cjs` | 앱 합류·귀환·제외, 체력 유지, 목록 응답 순서 |
| `turn-ui-smoke.cjs`, `brawl-ui-smoke.cjs` | 던전 턴제 스킬·효과, 배틀 난전·최후 생존자 |

실제 Windows 앱·투명 창과 아이콘 변환 검증:

```powershell
node tests/desktop-smoke.cjs
node tests/leisure-desktop-smoke.cjs
powershell -NoProfile -ExecutionPolicy Bypass -File tests/icon-orientation.ps1
```

Electron 검증은 별도 테스트 프로필을 사용합니다. 새 게임의 실제 앱 아이콘, 고정 위젯 크기와 최소화·복원 시 게임 중지·재개도 확인합니다.

## 현재 범위와 다음 개선 후보

현재 소스 실행 방식으로 제공하며, 설치형 EXE·자동 업데이트는 포함하지 않습니다. 게임을 바꾸거나 앱을 종료할 때 진행 중인 판을 저장해 그대로 이어 하는 기능도 제공하지 않습니다. 농장 성장·수집 데이터는 위 저장 규칙을 따릅니다.

다음 개선 후보는 작은 창의 조작 도움말, ㄴ·ㅗ 형태 등 쌓기 블록 다양화, 설치형 배포입니다. 현재 구현된 기능과 구분하기 위해 이 항목들은 계획으로만 기록합니다.
